Building Scalable Infrastructure for Vision–Language–Action Robot Learning:
From Data Scaling to Real-World Deployment

IROS 2026 Workshop

Introduction

Recent advances in Vision–Language–Action (VLA) models and embodied foundation models have demonstrated promising progress toward general-purpose robots. However, scaling robot learning beyond laboratory demonstrations is increasingly limited by system-level challenges rather than model architectures alone. Large-scale data acquisition, post-training methodologies, reliable evaluation, and real-robot deployment remain fragmented across different research efforts.

This workshop focuses on building the end-to-end infrastructure required for scalable robot learning, covering the full lifecycle from data scaling to deployment. The program combines invited keynote talks, spotlight presentations, interactive posters, and a panel discussion to examine four tightly connected stages of VLA development: data scaling, training, evaluation, and deployment infrastructure.

Discussions will address large-scale real and simulated data generation, post-training paradigms such as supervised fine-tuning and reinforcement learning, standardized evaluation protocols for embodied intelligence, and infrastructure supporting real-world robot execution and fleet learning. This multi-format structure is designed to connect algorithmic innovation with engineering practice and to encourage cross-disciplinary exchange between robotics, machine learning systems, and computer vision communities.

We expect the workshop to (i) clarify shared system challenges in scaling VLA post-training, (ii) promote reproducible evaluation and deployment practices, and (iii) catalyze reusable infrastructure design principles that enable continuous robot learning in real-world environments.

Key Topics & Discussion Pillars

This workshop focuses on four interconnected pillars:

1. Data Scaling

  • Scaling real-world robot interaction data collection
  • Simulation data generation and orchestration
  • Human-in-the-loop demonstrations and teleoperation
  • Synthetic multimodal data pipelines
  • Sim–real hybrid dataset construction

2. Training

  • Supervised fine-tuning and imitation learning
  • Offline and online reinforcement learning
  • Preference learning and feedback modeling
  • Continuous post-training workflows
  • Distributed experimentation and rollout systems

3. Evaluation

  • Benchmarking VLA capabilities and generalization
  • Algorithm comparison protocols
  • Real-robot evaluation methodologies
  • Safety and robustness assessment
  • Long-horizon and open-world task evaluation

4. Deployment Infrastructure

  • Real-robot execution systems
  • Safety monitoring and runtime diagnostics
  • Hardware–software integration pipelines
  • Continuous deployment and data feedback loops
